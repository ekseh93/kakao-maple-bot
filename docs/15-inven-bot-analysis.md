# 인벤 참고 글 분석 및 추가 기능 계획

분석 대상: [엔버봇 디스코드 인증 글](https://www.inven.co.kr/board/maple/2304/38561)

## 확인한 기능 범주

해당 글은 캐릭터 기본 정보, 전투력, 무릉, 유니온, 경험치 이력, HEXA, 장비/심볼, 심볼·HEXA 계산, 공지와 보스 정보 등을 하나의 봇에서 제공하는 사례입니다.

이 프로젝트에 적용할 때는 다음 원칙을 유지합니다.

- 캐릭터·심볼·HEXA·무릉·유니온 조회는 Nexon Open API만 사용합니다.
- 인벤 글의 명령어·응답을 복제하지 않고, 카카오톡에 맞는 짧은 응답으로 설계합니다.
- Maple.GG와 Maplescouter는 자동 조회하지 않고 링크만 생성합니다.
- 공식 API에 없는 전투력·환산·보스컷 값은 임의로 계산하거나 외부 사이트에서 가져오지 않습니다.

## 이번 반영

- `!정보 <닉네임>`을 `!캐릭터 <닉네임>`의 별칭으로 추가했습니다.
- `!심볼계산 <지역명> <현재레벨> <목표레벨> [현재성장치]`를 `!심볼`의 별칭으로 추가했습니다.
- `!헥사 <닉네임>`을 추가해 Nexon Open API의 장착 HEXA 코어 요약을 제공합니다.
- `!무릉 <닉네임>`을 추가해 Nexon Open API의 무릉도장 최고 기록을 제공합니다.
- `!유니온 <닉네임>`을 추가해 Nexon Open API의 유니온 요약을 제공합니다.
- `!장비 <닉네임>`을 추가해 Nexon Open API의 장착 장비 요약을 제공합니다.
- 기존 지역별 아케인·어센틱·그랜드 어센틱 심볼 계산식을 그대로 재사용합니다.

## 다음 추가 후보

| 우선순위 | 명령    | 필요한 공식 API | 비고                    |
| -------- | ------- | --------------- | ----------------------- |
| 1        | `!공지` | 공식 공지 API   | 최신 1~3건만, 캐시 필수 |

`!공지`는 Nexon Open API의 공지 목록만 사용하며, 공식 메이플스토리 링크를 그대로 제공합니다.

장비 응답은 부위·이름·스타포스·잠재 등급만 반환합니다. 실제 캐릭터 조회나 인벤/외부 사이트 자동 수집은 이 분석에 포함하지 않습니다.
