# 변경 기록

이 문서는 Kakao Maple Bot 저장소에 반영한 주요 변경을 구현 문서와 별도로 추적합니다.

## 2026-08-29

### 악몽·앵글·마운틴 경험치 계산 명령어

- 기존 `!에픽던전`을 `!악몽`으로 변경했습니다.
- `!앵글`과 `!마운틴`을 추가해 각각 앵글러 컴퍼니와 하이마운틴의 레벨별 기본 1판 경험치로 레벨업 예상 판수를 계산합니다.
- 참고 표: https://matsu1207.tistory.com/989, https://matsu1207.tistory.com/541
- 세 명령어 모두 Nexon Open API 최신 경험치 스냅샷을 사용하며 보너스 단계는 반영하지 않습니다.

### !에픽던전 경험치·레벨업 예상

- `!에픽던전 <닉네임>`이 Nexon Open API 경험치 이력의 최신 레벨·경험치율을 사용하도록 추가했습니다.
- 악몽선경 기본 보상 경험치표(280~299레벨)의 1판 상승률을 정적 데이터로 관리하고, 현재 레벨에서 100%까지 필요한 예상 판수를 올림 계산합니다.
- 참고 표: https://matsu1207.tistory.com/989
- 경험치 이력은 기존 `!경험치`와 같은 5분 캐시를 사용하며, 실시간 플레이 상태나 보너스 단계는 반영하지 않습니다.

## 2026-08-28

### 익명 일일 명령어 통계·포트폴리오 샘플

- Lambda가 원문·방·발신자 없이 도쿄 기준 날짜별 명령어 사용 감사 로그를 CloudWatch에 기록합니다.
- 로컬 집계 스크립트가 일별 호출 수·성공/실패·응답시간 통계만 생성합니다.
- GitHub 자동 쓰기는 추가하지 않고, 포트폴리오 샘플은 고정 가상 데이터로 별도 생성합니다.

### !핫딜 퀘이사존 6개·시각 표시

- 퀘이사존 섹션을 최신 6개로 확장하고 0번부터 번호를 표시합니다.
- 게시판 HTML의 작성 시각을 제목 뒤 `(시각)` 형식으로 표시합니다.
- 아카라이브와 에펨코리아의 최대 5개 표시 규칙은 유지합니다.

### !핫딜 3개 커뮤니티 통합

- `!핫딜`이 퀘이사존·아카라이브·에펨코리아에서 최신 글을 각각 최대 5개씩 조회하도록 확장했습니다.
- 결과를 사이트별 섹션과 게시판 링크로 나눠 모바일 카카오톡에서 읽기 쉽게 표시합니다.
- 사이트별 캐시와 stale fallback을 독립적으로 유지해 한 사이트의 403/429/일시 장애가 전체 응답을 막지 않도록 했습니다.
- `krepe90/user-hotdeal-bot`의 게시판별 파서·1페이지 요청 구조를 참고했으며, 현재 저장소의 TypeScript 계약과 보안 정책에 맞춰 별도 구현했습니다.

### !핫딜 퀘이사존 응답 보강

- `!핫딜`의 표시용 게시판 주소를 `https://quasarzone.com/bbs/qb_saleinfo`로 고정했습니다.
- 기본 게시판 요청이 403으로 거절될 때 정상적인 정렬 쿼리 요청을 한 번 시도하도록 보강했습니다.
- Cloudflare 챌린지 HTML은 게시글 데이터로 처리하지 않고 외부 서비스 오류로 분류합니다.
- 기존 5분 캐시와 6시간 stale fallback은 유지하며, 프록시·IP 변경·자동화된 차단 우회는 추가하지 않았습니다.

### 포트폴리오 공개 정리

- README에 현재 구현·도쿄 AWS 배포·자동 검증·사용자 제공 공기계 확인의 구분을 추가했습니다.
- 트러블슈팅 문서에 Terraform 경로·SSO 만료·MessengerBot R 레거시 콜백·오픈채팅 room 값·HTTP 200 빈 응답 문제와 해결 방법을 추가했습니다.
- 공개용 phone relay에서 실제 방 이름과 공유 secret을 제거하고 placeholder로 변경했습니다. 실제 값은 공기계의 비공개 복사본에만 입력합니다.
- 사용자 제공 채팅 화면은 명령어·봇 응답 영역만 남긴 비식별화 파생 이미지로 변환해 `docs/assets/`에 추가했습니다. 원본과 실제 대화 식별 정보는 커밋하지 않습니다.
- 과거 Git 커밋에 운영 secret이 포함된 이력을 발견해 운영 secret을 회전하고 이력 정리를 진행했습니다.
- README 영문판·일문판과 비식별화된 영문·일문 인증 이미지 변형을 추가했습니다.

### secret 회전 및 Git 이력 정리 완료

- 운영 Lambda의 `BOT_SHARED_SECRET`을 새 값으로 회전하고 Terraform apply 결과를 확인했습니다.
- 새 secret 기준 `/health` HTTP 200과 인증된 `!도움말` reply 응답을 확인했습니다.
- `codex/aws-tokyo-region`의 도달 가능한 Git 이력을 재작성하고 GitHub 원격 브랜치를 `--force-with-lease`로 갱신했습니다.
- `main` 브랜치는 변경하지 않았으며, secret 값은 로그·문서·커밋에 기록하지 않았습니다.
- 공기계 릴레이의 secret 교체·재컴파일은 사용자가 수행해야 하는 마지막 수동 단계입니다.

### !모니터 출력 축소

- `!모니터`를 디시인사이드 모니터 게시판 최신 글 5개 조회로 변경했습니다.
- 개별 게시글 링크를 제거하고 모니터 게시판 링크 하나만 하단에 표시합니다.

### !일본음식점 출력 축소

- `!일본음식점`을 음식점 말머리 게시판 최신 글 3개 조회로 변경했습니다.
- 개별 게시글 링크를 제거하고 음식점 게시판 링크 하나만 하단에 표시합니다.

### !일본여행기 출력 축소

- `!일본여행기`를 디시인사이드 일본여행 게시판 최신 글 3개 조회로 변경했습니다.
- 개별 게시글 링크를 제거하고 게시판 링크 하나만 하단에 표시합니다.

### 공개 게시판 장애 시 마지막 정상 결과 fallback

- `!핫딜`, `!글카`, `!모니터`, `!일본여행기`, `!일본음식점`에 5분 정상 캐시와 6시간 stale fallback을 추가했습니다.
- User-Agent 회전·프록시·IP 변경 등 접근제어 우회는 추가하지 않고, 원문이 일시 차단된 경우에는 마지막 정상 결과임을 표시합니다.

### !이벤트 최신 게시글 5개로 변경

- `!이벤트`가 진행 중 이벤트 전용 페이지가 아니라 메이플스토리 공식 이벤트 게시판에서 최신 게시글 5개를 조회하도록 변경했습니다.
- 개별 이벤트 링크는 응답에서 제거하고, 하단에 공식 이벤트 게시판 링크 하나만 표시합니다.

### 마빡도로시 공지글 제외

- `!마빡도로시` 검색 결과에서 인벤 게시판 상단 공지 행을 제외하고 실제 게시글 3개를 표시합니다.

### 핫딜 링크 출력 단순화

- `!핫딜` 결과에서 개별 게시글 링크를 제거했습니다.
- 하단에 퀘이사존 세일정보 게시판 링크 하나만 표시합니다.

### 웹소설 랜덤 추천 추가

- `!웹소설`을 추가해 카카오페이지·문피아·노벨피아의 공개 후보를 통합하고 무작위 작품을 추천합니다.
- 결과 제목 앞에 `[카페]`, `[문피아]`, `[노벨피아]` 출처를 표시합니다.

### 주유소 지역 필수 조회

- `!주유소 <지역>`으로 명령 형식을 변경했습니다.
- 지역을 생략하면 사용법 오류를 표시하고, 입력한 시·도 지역의 최저가 3곳만 조회합니다.

### 일본 만화 추천 소스 변경

- `!만화`의 데이터 소스를 나무위키에서 리디북스 일본 만화 목록으로 변경했습니다.
- 추천 데이터의 링크는 `https://ridibooks.com` 도메인으로 정규화합니다.

### 운세 로컬 어댑터 통합

- `!운세`에 출생시간 미입력용 로컬 fortune 어댑터를 연결했습니다.
- 별도 MCP HTTP 서버, Railway, 외부 운세 API를 사용하지 않아 운세 요청에 대한 별도 호출 비용이 발생하지 않는 구조입니다.
- 원본 `fortuneteller` MCP 서버는 출생시간을 요구하므로, 시간을 임의로 보정하지 않고 날짜·성별·달력·한국시간 기준일로 결정적인 오락용 결과를 생성합니다.
- 관련 요구사항: 운세 입력·한국시간·오락용 처리

### 상품·매장·영화관 OpenAPI facade 조회

- `!다이소`, `!상품비교`, `!매장`, `!재고`, `!영화관` 명령을 추가했습니다.
- LLM 없이 Lambda가 `mcp.aka.page`의 공개 GET action을 직접 호출합니다.
- 외부 등록·구매·예약·좌석 변경 기능은 연결하지 않았습니다.

### 전국 평균 유가 명령 추가

- `!기름`과 `!유가`를 같은 명령어 별칭으로 추가했습니다.
- 오피넷 전국 평균 유가를 읽기 전용으로 조회하고 10분간 캐시합니다.

### 전국 최저가 주유소 명령 추가

- `!주유소 [지역]`으로 오피넷 전국 또는 시·도별 휘발유 최저가 3곳을 가격순으로 표시합니다.
- 결과는 10분간 캐시하며, 읽기 전용 조회만 수행합니다.

### 달러·엔화 환율 명령 추가

- `!환율`을 추가해 1달러와 100엔의 원화 환산값을 표시합니다.
- API 키 없는 공개 환율 조회를 사용하며 결과는 1분간 캐시합니다.
- 공급자 갱신 주기 때문에 거래소 실시간 체결가와 다를 수 있음을 명시합니다.

### 주변 장소·다이소 상품 상세 명령 추가

- `!주변 <지역> [카테고리]`로 음식점·카페 등 주변 장소를 최대 5개 조회합니다.
- `!상품상세 <다이소상품ID>`로 상품 가격과 판매 상태를 조회합니다.
- 두 명령 모두 읽기 전용이며, 결과를 각각 1분·10분 캐시합니다.

### 리테일 명령 범위 정리

- `!주변`, `!상품상세`, `!상품비교`, `!매장`, `!재고`, `!영화관`을 제거했습니다.
- 현재 리테일 명령은 `!다이소` 상품 검색만 유지합니다.

### 디시인사이드 준수형 조회 보호

- 403/429 응답에서는 모바일 주소 재시도와 차단 회피를 수행하지 않도록 변경했습니다.
- 디시인사이드 목록 캐시를 5분으로 늘려 반복 호출과 서버 부담을 줄였습니다.

### 디시인사이드 모바일 fallback 추가

- `!모니터`, `!일본여행기`, `!일본음식점`은 데스크톱 페이지가 실패하면 모바일 페이지를 재시도합니다.
- 나무위키의 403 및 퀘이사존 Cloudflare 차단은 우회하지 않고 외부 서비스 제한으로 처리합니다.

### 한글 미국·일본 주식명 검색 보강

- 애플·엔비디아·테슬라·마이크로소프트 등 주요 미국 주식의 한글 별칭을 추가했습니다.
- 닌텐도·소니·도요타·혼다·소프트뱅크 등 주요 일본 주식의 한글 별칭을 추가했습니다.
- Yahoo Finance 검색 결과에서 미국시장·일본시장 후보를 분리해 표시합니다.

### 주식 응답 메타데이터 간소화

- `!주식` 결과에서 조회 시각과 투자 권유 안내 문구를 제거했습니다.
- 종목명·시장·현재가·전일 대비·데이터 기준은 유지합니다.

### 그래픽카드 게시판 고정글 제외

- `!글카`가 퀘이사존의 `타세요 게시판 특별 규정` 같은 고정 안내글을 제외합니다.
- 추천·제목 영역의 실제 게시글부터 최대 5개를 표시하도록 파싱을 보강했습니다.

### 전 세계 한글 날씨 검색 fallback 추가

- Open-Meteo가 한글 지역명을 찾지 못하면 OpenStreetMap Nominatim으로 한글 지명을 좌표로 변환합니다.
- Nominatim 요청에는 식별 가능한 User-Agent를 사용하고, 기존 5분 날씨 캐시와 요청 제한을 유지합니다.
