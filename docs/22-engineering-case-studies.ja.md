# 技術事例：問題から検証まで

KakaoTalkやMapleStoryを知らなくても読めるよう、境界の設計と検証方法に絞った事例集です。コード作成・調査にはAI支援を使用しています。過去の対応と今回の検証は区別します。

## 1. 秘密情報スキャナーの誤検出と見逃し

**課題。** PR #9のCIが、検査用に書いた正規表現と安全なplaceholderを秘密情報として検出しました。一方、引用符や空白を含む代入は正しく検出できない場合がありました。

**判断。** 検査対象を広く除外する方法は見逃しを増やします。検査処理を独立させ、例示値と設定参照を区別し、検出した値そのものをログへ出さない構造にしました。

**実装とレビュー。** 検出結果はファイル・行・規則名に限定します。CodeRabbitによる代入形式の指摘を受け、空白・引用符・placeholderの回帰テストを追加しました。ドキュメントのCI一覧も実際のワークフローに合わせて修正しました。

**証拠。** [PR #9](https://github.com/ekseh93/kakao-maple-bot/pull/9) · [検出処理](../scripts/secret-check-core.mjs) · [回帰テスト](../scripts/secret-check.test.mjs) · [詳細な障害記録](13-troubleshooting.md)

**限界。** 独自のパターン検査は、あらゆる秘密情報や個人情報を検出するものではありません。現在の追跡ファイルを検査しても、過去のGit履歴の安全性は保証できません。

## 2. 任意の外部APIが主応答を止める問題

**課題。** 天気の取得では、気温・湿度と大気質を別APIから取得します。大気質だけの障害でも全体を失敗にすると、取得済みの天気まで利用者へ返せません。

**判断。** 気温・湿度を主情報、大気質を任意情報としました。大気質には親リクエストの中断を引き継ぐ1.2秒の時間制限を設けます。

**今回の検証で見つかった不足。** 後続ブランチではHTTP取得の失敗を処理していましたが、成功レスポンスのJSON解析失敗はその外にありました。また、タイマーの解除が本文解析より前だったため、ヘッダー取得後に本文が遅れる場合を十分に扱えていませんでした。

**修正。** 本文の読み取りと任意フィールドの検証まで同じ失敗処理に含め、処理完了後にタイマーと親イベントリスナーを解除します。大気質が不正なJSONや型だった場合はPM値を省略します。

**再現テスト。** HTTPエラー、不正JSON、null、数値の型不一致、本文待ちの中断を固定データで検証します。時間制限は仮想時計で進めるため、実APIの応答速度に依存しません。

**証拠。** [Issue #10](https://github.com/ekseh93/kakao-maple-bot/issues/10) · [実装](../packages/providers/src/index.ts) · [テスト](../tests/providers.test.ts)

**限界。** これはコード内の時間制限と部分失敗の検証です。世界各地の実API応答速度や、本番p95の改善を測定した結果ではありません。主情報のAPIまで失敗した場合はエラーを返します。

## 3. HTTP 200でもチャットに返答がない

**課題。** バックエンドはHTTP 200を返す一方、端末に返答が表示されない事象がありました。端末から渡された部屋情報と許可リストの不一致により、応答本文がnullとなる経路がありました。

**診断。** 端末で受け取ったコールバック、HTTP応答、バックエンドの許可判定を別々に確認しました。HTTP 200だけではチャット全体の成功を判断できません。

**設計上の意味。** `reply: null` は、非コマンドや未許可の要求を無視するための正常な契約でもあります。エラーと混同せず、端末の受信確認とバックエンドの認証・許可テストを分ける必要があります。

**トレードオフ。** 端末の固定部屋設定はコールバックの制約への対応ですが、バックエンドへ渡す部屋名を固定することは、端末が受信した元の部屋を認証することではありません。名前だけの識別に強い認証保証を付けないようにしています。

**証拠。** [過去の診断記録](13-troubleshooting.md) · [HTTP境界のテスト](../tests/lambda.test.ts) · [端末E2Eチェックリスト](16-phone-e2e-checklist.md)

**限界。** 実利用は利用者確認です。端末再起動や長時間稼働を含む独立検証は[Issue #7](https://github.com/ekseh93/kakao-maple-bot/issues/7)で未完了として扱います。
