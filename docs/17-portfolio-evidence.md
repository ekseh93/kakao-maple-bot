# 포트폴리오 인증·공개 범위

이 문서는 Kakao Maple Bot을 취업 포트폴리오로 소개할 때 사용할 수 있는 검증 자료와 개인정보 보호 범위를 정리합니다.

## 공개 가능한 자료

- TypeScript 기반 Lambda 명령 라우터와 계산·공급자 어댑터 구조
- 도쿄 리전 AWS Lambda/API Gateway의 IaC 설계
- 자동 테스트·정책 검사·폰 릴레이 구문 검사 결과
- 명령어 입력과 봇 응답이 보이는 개인정보 비식별화 화면

## 비식별화 화면

![Kakao Maple Bot 개인정보 비식별화 인증 화면](assets/kakao-bot-evidence-redacted.png)

이 이미지는 사용자가 제공한 운영 화면을 바탕으로 만든 비식별화 파생 자료입니다. 명령어·봇 응답 영역은 기능 흐름을 보여주기 위해 남겼고, 대화 상대·방 식별자·아바타·일반 대화·시각·URL 등은 모자이크 또는 숨김 처리했습니다. 생성·편집 과정에서 글자가 변형될 수 있으므로 정확한 명령 결과의 근거로 사용하지 않습니다.

## 검증 상태 구분

| 항목 | 상태 | 증거 범위 |
| --- | --- | --- |
| 로컬 TypeScript·테스트·정책 검사 | 저장소 명령으로 확인 | 자동화된 로컬 결과 |
| AWS `/health` 및 인증 API smoke test | Codex가 확인 | 도쿄 리전 배포 endpoint |
| 공기계 MessengerBot R 사용 | 사용자 확인 | 사용자가 실제 기기에서 확인한 운영 결과 |
| 카카오톡 전체 대화·계정 정보 | 공개하지 않음 | 개인정보 및 계정 식별 정보 |

## 공개 전 보안 규칙

1. `bot.js`의 `sharedSecret`, Terraform 비밀 변수, API 키는 placeholder 또는 빈 예시 값만 공개합니다.
2. 실제 방 이름과 카카오 식별자는 문서·스크린샷·커밋 메시지에 기록하지 않습니다.
3. 원본 캡처는 저장소에 복사하지 않으며, 공개용 파생 이미지만 사용합니다.
4. 과거 Git 이력에 실제 secret이 남아 있으면 secret을 먼저 회전하고, 이력 제거와 force-push는 별도 승인 후 수행합니다.
5. 공개 자료에는 관측한 결과만 적고, 배포·공기계 동작을 추정해서 기재하지 않습니다.
