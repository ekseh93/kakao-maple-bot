# 제품 요구사항 정의서

문서 버전: 1.0  
기준일: 2026-08-26  
상태: 구현 승인용 기준선

## 1. 제품 개요

Kakao Maple Bot은 지인 중심 카카오톡 채팅방에서 반복적으로 찾는 메이플스토리 정보와 소규모 오락·생활 정보를 짧은 텍스트 답변으로 제공하는 개인용 봇입니다. Android 공기계의 별도 카카오 계정이 메시지를 수신·답장하고, 외부 API 및 계산은 원격 백엔드가 담당합니다.

## 2. 문제 정의

- 메이플 캐릭터 정보와 심볼 계산을 위해 여러 웹사이트를 반복 방문해야 합니다.
- 단체 채팅에서 가위바위보, 항목 선택, 메뉴 추천을 즉시 실행하기 어렵습니다.
- 공기계에 모든 계산과 API 키를 넣으면 수정·테스트·비밀 관리가 어렵습니다.
- 제3자 환산 사이트를 그대로 자동 호출하면 약관·저작권·안정성 문제가 생깁니다.

## 3. 목표

1. 명령 입력 후 한 번의 짧은 답변으로 핵심 결과를 제공합니다.
2. 공식 API와 자체 계산을 우선해 데이터 출처와 책임 경계를 명확히 합니다.
3. 공기계 교체 없이 서버 코드만으로 대부분의 기능을 갱신할 수 있게 합니다.
4. 무료 범위에서 운영할 수 있고 취업 포트폴리오로 설명 가능한 구조와 테스트를 갖춥니다.
5. 카카오·외부 서비스의 정책 위험을 기능 수준에서 낮춥니다.

## 4. 비목표

- 카카오 정책 우회, 프로토콜 역분석, 보호조치 무력화
- 대량 메시지·광고·홍보·자동 초대·자동 친구 추가
- Maple.GG 또는 Maplescouter의 크롤링·비공개 API 사용·결과 복제
- 실제 주식 주문, 자동매매, 종목 추천, 수익 보장
- 환산주스탯 전체 로직의 무단 복제
- 카카오 대화 보관·검색·사용자 프로파일링
- 유료 상용 서비스 및 SLA 보장

## 5. 대상 사용자

### 주 사용자

- 운영자 본인과 동의한 지인
- 메이플스토리를 플레이하며 카카오톡에서 빠른 조회를 원하는 사용자

### 운영자

- Android 공기계와 봇 계정을 관리합니다.
- Nexon·KRX·Tiingo·AWS 계정과 키를 직접 발급·보관합니다.
- 허용 채팅방, 기능 활성화, 긴급 중지를 관리합니다.

## 6. 대표 사용자 시나리오

### 캐릭터 조회

사용자가 “!정보 캐릭터명”을 보내면 봇은 Nexon Open API 기준 월드, 직업, 레벨, 길드, 전투력 등 핵심 정보와 데이터 기준 시각을 답합니다. 기존 `!캐릭터`는 호환용 별칭으로 유지합니다. 자세한 내용은 외부 사이트 링크로 이동합니다.

### 심볼 계산

사용자가 “!심볼 여로 1 20” 또는 “!심볼 기어드락 1 11”을 보내면 봇은 해당 심볼 레벨 구간에 필요한 성장치 합계를 계산하고 공식·프로젝트 계산 기준일을 표시합니다.

### 채팅 놀이

사용자가 “!짜장vs짬뽕”을 보내면 두 항목 중 하나를 균등 확률로 선택하고 “항목 승리!” 형식으로 답합니다. 결과는 재현성을 요구하지 않습니다.

### 메뉴 추천

사용자가 “!뭐먹지”를 보내면 저장소에서 관리하는 전체 메뉴 목록에서 하나의 추천 결과를 출력합니다. `소재획`과 `재획비`는 각각 기본 메뉴보다 3000% 높은 가중치(31배)로 추첨합니다. 식당·가격·영업시간 정보는 MVP에서 제공하지 않습니다.

### 국내 주식 시세

사용자가 “!주식 삼성전자” 또는 “!주식 Tesla”를 보내면 국내는 KRX Open API, 미국은 Tiingo에서 제공하는 일별 시세를 참고용으로 표시합니다. API가 구성되지 않았다면 설정되지 않은 기능임을 명확히 답합니다.

## 7. 성공 지표

MVP는 상용 KPI 대신 검증 가능한 품질 지표를 사용합니다.

- 지원 명령 정상 응답률 95% 이상: 외부 공급자 장애 제외, 시험 100건 기준
- 계산 명령 단위 테스트 100% 통과
- 캐시 적중 또는 로컬 명령 p95 응답 1초 이내
- 외부 API 명령 p95 백엔드 응답 4초 이내
- 비명령 메시지 응답 0건
- 비밀정보 Git 노출 0건
- 외부 사이트 자동 접근 0건
- 공기계 24시간 시험 중 중복 답장 0건

## 8. 제약과 가정

- KakaoTalk 일반 계정 자동화는 공식 챗봇 경로가 아니며 계정 제한 가능성이 있습니다.
- Android 알림 접근과 백그라운드 실행이 제조사 절전 정책의 영향을 받습니다.
- Nexon 데이터는 실시간과 차이가 있을 수 있으며 API 공지의 갱신 시차를 따릅니다.
- KRX Open API와 Tiingo 사용에는 운영자 명의의 인증정보 발급이 필요합니다.
- AWS Free Tier·예산 알림과 각 API 이용 정책은 구현·배포 전에 다시 확인합니다.
- 운영자는 허용된 소수 채팅방에서만 시험하고 참여자에게 봇임을 알립니다.

## 9. 릴리스 범위

### MVP

- 공기계 릴레이
- 헬스체크·공유 비밀 인증
- 도움말, 캐릭터, 지역별 아케인/어센틱 심볼, 가위바위보, vs 메뉴 선택, 뭐먹지
- 선택형 국내 주식 조회
- 타임아웃, 오류 메시지, 최소 로그, 테스트, 운영 문서

### MVP 이후

- 보스 일정과 이벤트 알림
- 유니온·장비·심볼 착용 상세
- 방별 기능 토글과 관리자 명령
- 사용자 동의 기반 즐겨찾기
- 공식 허가를 받은 외부 서비스 연동
