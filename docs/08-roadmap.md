## Phase 6 — 운영 안정화 (로컬 안전성 보완 완료, 운영 시험 전)

범위:

- 24시간 soak test
- 운영 런북 실제 검증
- 응답 길이·캐시·rate limit 조정
- 최신 약관 재검토

현재 로컬 단계에서는 비식별 구조화 로그 필드, 16 KiB HTTP 본문 상한, 공급자 timeout 오류 매핑을 검증했습니다. 24시간 soak test와 실제 런북 검증은 배포·공기계 승인 후 수행합니다.

Bearer 인증 비교는 입력 길이를 포함해 일정 시간 비교하도록 구현했으며, malformed JSON·필수 필드 누락도 경계에서 거부합니다.

공급자 어댑터는 네트워크 오류와 5xx에만 1회 재시도하고, 429는 즉시 사용자용 제한 오류로 매핑합니다.

Rate limit은 명령으로 판정된 요청에만 적용하며, 방당 10초 5건·발신자당 1분 10건·전체 1분 60건을 초과하면 공급자 호출 없이 차단합니다.

`pnpm policy:check`는 코드 영역에서 Maple.GG·Maplescouter 자동 접근과 명백한 secret assignment를 검사합니다.

`pnpm phone:check`는 MessengerBot R 릴레이 단일 JavaScript 파일의 구문만 검사하며, 실제 앱 컴파일·기기 실행을 대신하지 않습니다.

HTTP 본문은 헤더 유무와 관계없이 UTF-8 인코딩 크기를 다시 확인해 16 KiB를 초과하면 413으로 거부합니다.

요청 처리 시 만료된 중복 이벤트·rate-limit 버킷·공급자 캐시를 정리해 장시간 실행되는 Lambda 인스턴스의 메모리 증가를 제한합니다.

KIS 현재가 fixture의 가격·등락·등락률·거래량은 유한 숫자인지 런타임에서 검증하며, 타입이 바뀐 응답은 `PROVIDER_SCHEMA`로 격리합니다.

Nexon fixture도 OCID와 캐릭터명 타입을 런타임 검증해 비문자열 응답을 사용자 출력으로 변환하지 않습니다.

Nexon 기본 정보의 레벨·월드·직업·길드 선택 필드도 타입 변경 시 누락 처리하지 않고 `PROVIDER_SCHEMA`로 격리합니다.

Lambda HTTP 계약 테스트는 구성된 주식 조회의 조회 시각·비권유 문구와 비관리자의 `!상태` 무응답도 확인합니다.

캐릭터 정상 응답에는 URL 인코딩된 Maple.GG 상세 링크를 포함하며, 링크 생성 외 제3자 사이트 접근은 하지 않습니다.

관리자 `!상태` 응답은 공급자 구성 여부만 표시하고 secret·허용 방·내부 URL은 출력하지 않습니다.

KIS OAuth 토큰은 메모리에서 만료 5분 전까지 재사용하며, 토큰 값은 응답·로그·저장소에 기록하지 않습니다.

도움말에는 캐릭터 링크와 관리자 전용 상태 명령을 포함해 등록된 MVP 명령과 동기화했습니다.

캐릭터·주식 공급자 데이터로 조합되는 응답은 1,000자에서 잘라 비정상적으로 긴 외부 문자열이 채팅 답변을 폭주시키지 않도록 합니다.

- 계정 위험을 수용하지 않으면 공식 Kakao 채널 방식으로 재설계
