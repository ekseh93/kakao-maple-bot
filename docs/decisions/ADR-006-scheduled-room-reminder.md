# ADR-006: 동의된 방의 주간 리마인더 예약 발신

## 상태

승인된 제한 범위로 적용

## 결정

매주 수요일 `Asia/Seoul` 기준 18:00, 22:00, 22:30과 23:00에 공기계 MessengerBot R 릴레이가 `noticeRooms`에 설정된 방으로 다음 문구를 한 번씩 발신합니다.

```text
★보스☆수로☆ 플래그★
```

## 이유

AWS Lambda/API Gateway는 카카오톡 방으로 먼저 메시지를 보낼 연결을 갖고 있지 않습니다. 따라서 명시적으로 동의된 방 이름을 알고 있고 `Api.replyRoom`을 사용할 수 있는 공기계 릴레이에서 예약 여부를 판정합니다. 백엔드는 계속 요청/응답 및 데이터 처리만 담당합니다.

## 제한과 잔여 위험

- 저장소의 공개 스크립트에는 실제 방 이름을 넣지 않고 `noticeRooms` 로컬 설정으로 주입합니다.
- 불특정 다수 방, 광고성 발신, 자동 친구 추가에는 사용하지 않습니다.
- 릴레이 앱·Android 백그라운드 실행·배터리 최적화 제외가 유지되어야 합니다.
- 실행 중단 후 재시작하면 런타임 중복 방지 상태가 초기화되어 같은 슬롯이 다시 발신될 수 있습니다.
- 스케줄 검사는 30초 간격이므로 앱이 해당 시각에 실행 중이어야 하며, 기기 시간 계산은 UTC+9(`Asia/Seoul`)로 고정합니다.
