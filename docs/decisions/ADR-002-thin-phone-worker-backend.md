# ADR-002: 얇은 공기계와 백엔드 분리

상태: Accepted  
일자: 2026-08-26

## 배경

공기계 단일 스크립트에 명령·계산·외부 API를 모두 넣으면 테스트, 배포, 비밀 관리, 장애 격리가 어렵습니다.

## 결정

공기계는 HTTPS 릴레이와 최종 답장만 담당합니다. 명령 라우팅, 계산, 캐시, 공급자 호출은 TypeScript 서버리스 백엔드에 둡니다. 초기 Cloudflare Worker 선택은 ADR-005에서 AWS Lambda로 대체했습니다.

## 결과

- 대부분의 기능을 공기계 재설치 없이 갱신 가능
- API 키를 공기계에서 분리
- core 단위 테스트와 공급자 contract test 가능
- 백엔드 장애 시 봇 기능이 중단되는 단일 의존성이 생김
- 공개 엔드포인트 보호와 무료 한도 관리가 필요
