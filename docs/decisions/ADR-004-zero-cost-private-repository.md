# ADR-004: 무료 범위·비공개 저장소 기본값

상태: Accepted  
일자: 2026-08-26

## 배경

프로젝트는 개인 취업 포트폴리오이며 실제 비용과 판매를 전제로 하지 않습니다. 초기 문서에는 정책 위험과 향후 비밀 구성이 포함됩니다.

## 결정

- 실제 현금 비용 목표는 0원
- Cloudflare와 외부 API의 무료 범위를 우선
- 유료 기능은 기본 비활성화
- GitHub 저장소는 사용자가 공개 전환을 요청하기 전까지 private
- 명시적 라이선스는 사용자 결정 전 추가하지 않음

## 결과

- 무료 한도 초과 방지를 위한 캐시와 rate limit이 필요
- 포트폴리오 공개 전 문서의 민감도·라이선스·상표 표기를 다시 검토
- 저장소 공개는 별도 결정
