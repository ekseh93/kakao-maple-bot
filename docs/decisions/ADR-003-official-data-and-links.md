# ADR-003: 공식 데이터 직접 조회와 제3자 링크 전용

상태: Accepted  
일자: 2026-08-26

## 배경

Maple.GG와 Maplescouter는 유용한 사용자 제작 서비스지만 자동 접근·복제·백엔드 이용은 약관과 안정성 문제가 있습니다. Maplescouter의 2026-07-11 약관은 이를 구체적으로 금지합니다.

## 결정

- 메이플 데이터는 Nexon Open API로 직접 조회
- 계산은 출처가 있는 자체 로직으로 구현
- Maple.GG와 Maplescouter는 사용자 클릭 링크만 제공
- 서면 허락 없이는 자동 접근 예외 없음

## 결과

- 제3자 사이트와 동일한 환산 결과를 보장하지 않음
- 자체 계산 정확성과 패치 추적 책임이 생김
- 약관 위반과 비공개 API 변경 위험을 크게 줄임
