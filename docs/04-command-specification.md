# 명령어 명세

문서 버전: 1.0  
기본 접두사: !

## 1. 공통 파싱 규칙

1. 메시지 앞뒤 공백을 제거합니다.
2. 첫 글자가 !가 아니면 아무 응답도 하지 않습니다.
3. 명령어는 한글·영문 별칭에서 대소문자를 구분하지 않습니다.
4. 명령과 첫 인수 사이는 하나 이상의 공백으로 구분합니다.
5. 전체 입력이 300자를 넘으면 외부 호출 없이 사용법 오류를 반환합니다.
6. 알 수 없는 명령은 짧은 도움말을 반환하되 방별 속도 제한을 적용합니다.

## 2. 명령 목록

### !캐릭터

별칭: !메이플, !캐릭

형식:

    !캐릭터 <캐릭터명>

처리:

1. 이름을 검증합니다.
2. Nexon Open API에서 OCID를 조회합니다.
3. 기본 정보와 종합 스탯을 조회합니다.
4. 가능한 필드만 짧게 포맷합니다.

정상 출력:

    [메이플 캐릭터]
    캐릭터명 @ 스카니아
    Lv. 280 / 비숍
    길드: 예시길드
    전투력: 12,345,678
    HEXA: 코어 2개 / 총 레벨 45
    HEXA 코어 목록:
    ▸ 마스터리: 테스트 코어 Lv.30
    ▸ 강화: 강화 코어 Lv.15
    기준: Nexon Open API 2026-08-26
    상세: https://maple.gg/u/...

필드가 없으면 해당 줄을 생략합니다. 0이나 빈 문자열을 “알 수 없음”과 혼동하지 않습니다.

오류:

- 인수 없음: 사용법 표시
- 캐릭터 없음: “캐릭터를 찾지 못했습니다.”
- API 제한/장애: “Nexon 조회가 잠시 지연되고 있습니다.”
- 키 미설정: 운영자용 구성 오류 코드와 사용자용 미설정 메시지

### !헥사

형식:

    !헥사 <캐릭터명>

Nexon Open API의 `character/hexamatrix`에서 장착 중인 HEXA 코어명, 레벨, 종류, 연결 스킬을 조회합니다. 카카오톡에서 읽기 쉽도록 캐릭터명·장착 코어 수·코어 유형·코어명·레벨·연결 스킬을 고정 템플릿으로 표시하며, 응답은 1,000자 이내로 제한합니다. HEXA 성장 계산은 공식 성장표 fixture가 확정된 후 별도 명령으로 추가합니다.

### !로얄

```text
/로얄 [개수] [결과확인옵션(true/false)]
```

Nexon 공식 확률형 아이템 페이지의 현재 로얄스타일 목록과 표기 확률을 읽어 확률 가중치로 추첨합니다. 개수는 1~25개이며 생략 시 10개입니다. `true`는 개별 결과를 표시하고 `false`는 상세 결과를 숨깁니다. 결과는 실제 캐시 아이템을 지급하거나 구매하지 않는 미니게임이며, 목록 조회 실패나 공식 표 형식 변경 시 임의의 목록으로 대체하지 않습니다. 공식 페이지 응답은 5분간 캐시합니다.

### !원더베리

```text
/원더베리 [개수] [결과확인옵션(true/false)]
```

Nexon 공식 위습의 원더베리 확률 페이지에서 가장 최근 확률표를 읽어 확률 가중치로 추첨합니다. 개수는 1~25개이며 생략 시 10개입니다. `true`는 개별 결과를 표시하고 `false`는 상세 결과를 숨깁니다. 결과는 실제 캐시 아이템을 지급하거나 구매하지 않는 미니게임이며, 목록 조회 실패나 공식 표 형식 변경 시 임의의 목록으로 대체하지 않습니다. 공식 페이지 응답은 5분간 캐시합니다.

### !부티크

형식:

    !부티크

넥슨 공식 부티크 기프트 확률표를 기준으로 11개를 엽니다. 1~9번째는 일반 확률표, 10번째는 공식 설명에 따라 피버 타임 확률표, 11번째는 다시 일반 확률표를 사용합니다. 결과는 실제 아이템을 지급하지 않는 미니게임이며, 확률표 조회 실패나 형식 변경 시 임의의 결과로 대체하지 않습니다. 확률표는 5분간 캐시합니다.

### !루나스윗

```text
!루나스윗
```

원더 블랙 + 원더 블랙 조합 1회의 결과를 Nexon 공식 확률 페이지의 현재 확률표로 추첨합니다. 명령어는 인자를 받지 않으며 실제 캐시 아이템을 지급하거나 구매하지 않는 미니게임입니다.

### !루나드림

```text
!루나드림
```

원더 스윗 + 원더 블랙 조합 1회의 결과를 Nexon 공식 확률 페이지의 현재 확률표로 추첨합니다. 명령어는 인자를 받지 않으며 실제 캐시 아이템을 지급하거나 구매하지 않는 미니게임입니다.

### !날씨

```text
!날씨 <지역명>
```

Open-Meteo Geocoding으로 전 세계 지역명을 좌표로 찾은 후 현재 날씨 API와 Air Quality API에서 현재 상태·기온·습도·PM10·PM2.5를 조회합니다. 지역명은 공백을 포함할 수 있으며, 결과는 5분간 캐시합니다. 대기질 수치는 관측소 실측값이 아닌 Open-Meteo 모델 기반 참고값입니다.

### !무릉

형식:

    !무릉 <캐릭터명>

Nexon Open API의 `character/dojang`에서 무릉도장 역대 최고 층수, 기록 시간, 기록일을 조회합니다.

### !유니온

형식:

    !유니온 <캐릭터명>

캐릭터명을 OCID로 변환한 뒤 Nexon Open API의 `user/union`에서 유니온 레벨·등급과 제공되는 아티팩트 요약을 조회합니다.

### !유챔

형식:

    !유챔 <캐릭터명>

캐릭터명을 OCID로 변환한 뒤 Nexon Open API의 `user/union-champion`에서 해당 계정의 유니온 챔피언 이름·등급·직업·휘장 능력치를 조회합니다. API 응답 기준이며 챔피언 능력치를 직접 계산하거나 추정하지 않습니다.

### !장비

형식:

    !장비 <캐릭터명>

캐릭터명을 OCID로 변환한 뒤 Nexon Open API의 `character/item-equipment`에서 장착 장비의 부위·이름·스타포스·잠재능력 등급을 조회합니다. 카카오톡에서 읽기 쉽도록 캐릭터명·장착 장비 수·부위별 장비명·스타포스·잠재/에디 등급을 고정 템플릿으로 표시합니다. 잠재능력 옵션의 상세 문구는 응답 길이와 개인정보 최소화를 위해 반환하지 않으며, 응답이 1,000자를 넘으면 일부 장비만 표시합니다.

### !경험치 또는 /경험치

형식:

    /경험치 <캐릭터명>

Nexon Open API의 `character/basic`을 당일과 이전 7일 날짜로 조회해 총 8개의 경험치 스냅샷을 표시합니다. 각 날짜의 레벨·보유 경험치·경험치 비율과 같은 레벨을 유지한 경우의 7일 변화·일평균을 제공합니다. API의 날짜별 데이터 특성상 레벨업이 포함된 기간의 비율 변화는 단순 비교하지 않습니다.

### !썬데이 / !선데이

형식:

    !썬데이

Nexon Open API의 공지 목록에서 제목에 `썬데이` 또는 `선데이`가 포함된 가장 최근 항목의 제목·게시일·공식 링크를 표시합니다. 진행 중 이벤트 목록에 없더라도 공식 공지 목록을 보조 조회하며, 결과는 5분간 캐시합니다.

### !공지

형식:

    !공지

Nexon Open API의 `notice`에서 최신 공지 최대 3건의 제목·날짜·공식 링크만 조회합니다. 공지 본문은 가져오지 않으며, 목록은 5분간 캐시합니다.

### 공지 키워드 자동 알림

Nexon 공식 공지 목록을 공기계 릴레이가 약 60초마다 확인합니다. 제목에 `채널 점검`, `마이너버전`, `클라이언트` 중 하나가 포함된 새 게시글만 허용 방에 한 번 전달합니다. 기존 게시글은 릴레이 시작 시 기준 목록으로 등록하며, URL을 중복 키로 사용합니다. 이 기능은 `NOTICE_ALERT_ENABLED=true`일 때만 동작합니다.

### !인벤

형식:

    !인벤

메이플스토리 인벤 자유 게시판의 공개 10추 모음(`my=chu`)에서 최신 게시글 5개의 제목만 조회합니다. 게시글 본문·작성자·댓글·추천 수는 가져오지 않으며, 응답 마지막에 10추 게시판 링크를 표시합니다. 결과는 1분간 캐시하고 외부 페이지 구조 변경·접속 제한 시 표준 외부 조회 오류를 반환합니다.

### !일본여행

형식:

    !일본여행

저장소에 관리하는 정적 여행지 목록에서 일본의 현·도와 대표 도시를 하나 추천합니다. 외부 API를 호출하지 않으며, 추천 결과에는 간단한 여행 포인트를 표시합니다.

### !이벤트

형식:

    !이벤트

Nexon Open API의 `notice-event`에서 현재 진행 중인 이벤트 전체 목록의 제목·기간·공식 링크를 조회합니다. 목록은 5분간 캐시하며, 카카오톡 1,000자 제한을 넘으면 뒤쪽 항목을 생략하고 생략 건수를 표시합니다.

### !심볼

형식:

    !심볼 <지역명> <현재레벨> <목표레벨> [현재성장치]

지역명:

- 아케인: 여로(소멸의 여로), 츄츄, 레헬른, 아르카나, 모라스, 에스페라
- 어센틱: 세르니움, 아르크스, 오디움, 도원경, 아르테리아, 카르시온
- 그랜드 어센틱: 탈라하트, 기어드락

범위:

- 아케인: 레벨 1~20
- 어센틱: 레벨 1~11
- 목표레벨은 현재레벨보다 커야 함
- 현재성장치는 현재 레벨의 다음 강화 요구치 미만

출력:

    [아케인심볼 계산]
    Lv.1 → Lv.20
    남은 성장치: 2,679개
    현재 성장치 반영: 0개
    레벨업 메소: 252,470,000메소
    계산 기준: 2026-08-27

계산 계약:

- 레벨별 필요 성장치와 강화 메소는 별도 versioned data로 관리합니다.
- 가격은 지역별 레벨업 비용을 합산하며, 현재 성장치는 성장치만 차감하고 메소 비용에는 영향을 주지 않습니다.
- 아케인·어센틱·그랜드 어센틱 표의 기준일은 2026-08-27입니다. 패치로 비용이 바뀌면 표와 golden test를 함께 갱신해야 합니다.
- 공식 기준: [메이플스토리 아케인포스/어센틱포스 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/396)

### !가위 / !바위 / !보

입력한 손동작과 봇의 무작위 손동작을 비교합니다. 봇이 이기면 장난스러운 멘트를 덧붙이고, 사용자가 이기면 축하 멘트를 덧붙입니다.

### !골라

별칭: !선택

형식:

    !골라 <항목1>,<항목2>[,<항목3>...]

규칙:

- 쉼표 기준 2~20개
- 앞뒤 공백 제거
- 빈 항목 제거
- 항목당 최대 30자
- 동일 항목은 중복 제거 후 선택

출력: “제가 고른 건: 항목”

### !뭐먹지

별칭: !메뉴, !뭐먹을까

형식:

    !뭐먹지

입력은 명령어만 허용합니다. 카테고리 인자는 더 이상 사용하지 않습니다.

출력:

- 전체 요리 목록과 각 추첨 확률
- 확률 기반 추천 결과 1개
- `재획`은 다른 음식의 기본 가중치 1보다 50% 높은 1.5 가중치를 적용

데이터: 저장소의 검토된 정적 목록

알레르기, 종교, 건강 상태를 추론하지 않습니다. MVP는 식당 추천이나 위치 접근을 하지 않습니다.

### !주식

형식:

    !주식 <국내 종목명 또는 6자리 코드>
    !주식 <미국 종목명 또는 티커>

정상 출력:

    [주식 시세]
    삼성전자 (005930)
    현재가: 00,000원
    전일 대비: +000원 (+0.00%)
    거래량: 0,000,000
    조회: 2026-08-26 15:30 KST
    참고용 정보이며 투자 권유가 아닙니다.

규칙:

- 국내 종목은 KRX Open API의 일별 종가, 미국 종목은 Tiingo의 일별 종가, 일본 종목은 Yahoo Finance 공개 조회의 일별 데이터를 사용합니다.
- 주문·계좌·잔고 API는 호출하지 않습니다.
- 국내 종목명은 KRX 종목기본정보에서, 미국 종목명은 Tiingo 검색 결과에서, 일본 종목명은 Yahoo Finance 검색 결과에서 확인합니다.
- 같은 이름으로 여러 시장 후보가 확인되면 한국시장(KRX)·일본시장·미국시장으로 구분해 표시합니다.
- 일본 조회는 별도 API 키 없이 Yahoo Finance 공개 엔드포인트를 사용하므로 응답 형식 변경이나 일시적인 차단 가능성이 있습니다.
- 장외 시간에는 공급자가 제공한 마지막 값임을 표시합니다.
- 공급자 미설정 시 키 발급 안내 URL을 직접 노출하지 않고 “운영자가 설정하지 않은 기능”이라고 답합니다.
