# 명령어 명세

문서 버전: 1.0  
기본 접두사: !

## 1. 공통 파싱 규칙

1. 메시지 앞뒤 공백을 제거합니다.
2. 첫 글자가 !가 아니면 아무 응답도 하지 않습니다.
3. 명령어는 한글·영문 별칭에서 대소문자를 구분하지 않습니다.
4. 명령과 첫 인수 사이는 하나 이상의 공백으로 구분합니다.
5. 전체 입력이 300자를 넘으면 외부 호출 없이 사용법 오류를 반환합니다.
6. 알 수 없는 명령은 짧은 도움말을 반환하되 방별 속도 제한을 적용합니다.

## 2. 명령 목록

### !도움말

별칭: !명령어, !help

입력: 없음  
출력: 현재 활성화된 명령과 대표 예시  
오류: 없음

예시:

    [봇 도움말]
    !캐릭터 닉네임
    !심볼 아케인 1 20
    !주사위 100
    !골라 짜장,짬뽕
    !뭐먹지 한식
    !주식 005930

### !캐릭터

별칭: !메이플, !캐릭

형식:

    !캐릭터 <캐릭터명>

처리:

1. 이름을 검증합니다.
2. Nexon Open API에서 OCID를 조회합니다.
3. 기본 정보와 종합 스탯을 조회합니다.
4. 가능한 필드만 짧게 포맷합니다.

정상 출력:

    [메이플 캐릭터]
    캐릭터명 @ 스카니아
    Lv. 280 / 비숍
    길드: 예시길드
    전투력: 12,345,678
    기준: Nexon Open API 2026-08-26
    상세: https://maple.gg/u/...

필드가 없으면 해당 줄을 생략합니다. 0이나 빈 문자열을 “알 수 없음”과 혼동하지 않습니다.

오류:

- 인수 없음: 사용법 표시
- 캐릭터 없음: “캐릭터를 찾지 못했습니다.”
- API 제한/장애: “Nexon 조회가 잠시 지연되고 있습니다.”
- 키 미설정: 운영자용 구성 오류 코드와 사용자용 미설정 메시지

### !메이플링크

형식:

    !메이플링크 <캐릭터명>

출력:

    [외부 상세보기]
    Maple.GG: https://maple.gg/u/<URL-encoded-name>
    환산주스탯: https://maplescouter.com/ko
    외부 사이트에서 직접 검색해 확인하세요.

Maplescouter 자동 검색·조회 결과를 만들지 않습니다. 검증되지 않은 내부 딥링크보다 서비스 공식 진입 링크를 우선합니다.

### !심볼

형식:

    !심볼 <아케인|어센틱> <현재레벨> <목표레벨> [현재성장치]

범위:

- 아케인: 레벨 1~20
- 어센틱: 레벨 1~11
- 목표레벨은 현재레벨보다 커야 함
- 현재성장치는 현재 레벨의 다음 강화 요구치 미만

출력:

    [아케인심볼 계산]
    Lv.1 → Lv.20
    남은 성장치: 2,679개
    현재 성장치 반영: 0개
    계산 기준: 2026-08-26
    메소 비용은 MVP 계산에서 제외됩니다.

계산 계약:

- 레벨별 필요 성장치는 별도 versioned data 또는 검증된 순수 함수로 관리합니다.
- 수치는 공식 가이드와 게임 내 표본으로 이중 검증한 후 golden test에 고정합니다.
- 문서 예시 수치는 구현 전에 golden fixture와 다시 대조하며, 대조 전에는 코드에 그대로 복사하지 않습니다.
- 강화 메소 비용은 지역별·패치별 표가 검증되기 전까지 제공하지 않습니다.

### !주사위

형식:

    !주사위 [면수]

기본값: 6  
면수: 2~1000 정수  
출력: “🎲 1~N 결과: X”

암호학적 난수나 공정성 증명이 필요한 게임·도박 용도로 사용하지 않습니다.

### !골라

별칭: !선택

형식:

    !골라 <항목1>,<항목2>[,<항목3>...]

규칙:

- 쉼표 기준 2~20개
- 앞뒤 공백 제거
- 빈 항목 제거
- 항목당 최대 30자
- 동일 항목은 중복 제거 후 선택

출력: “제가 고른 건: 항목”

### !뭐먹지

별칭: !메뉴, !뭐먹을까

형식:

    !뭐먹지 [전체|한식|중식|일식|양식|분식|야식|가벼운]

입력 없음: 전체  
출력: 카테고리와 메뉴 하나  
데이터: 저장소의 검토된 정적 JSON

알레르기, 종교, 건강 상태를 추론하지 않습니다. MVP는 식당 추천이나 위치 접근을 하지 않습니다.

### !주식

형식:

    !주식 <국내 6자리 종목코드>

정상 출력:

    [국내 주식 시세]
    삼성전자 (005930)
    현재가: 00,000원
    전일 대비: +000원 (+0.00%)
    거래량: 0,000,000
    조회: 2026-08-26 15:30 KST
    참고용 정보이며 투자 권유가 아닙니다.

규칙:

- 한국투자 Open API 현재가 조회만 사용합니다.
- 주문·계좌·잔고 API는 호출하지 않습니다.
- 종목명 검색은 신뢰할 수 있는 코드 목록이 추가된 이후로 미룹니다.
- 장외 시간에는 공급자가 제공한 마지막 값임을 표시합니다.
- 공급자 미설정 시 키 발급 안내 URL을 직접 노출하지 않고 “운영자가 설정하지 않은 기능”이라고 답합니다.

### !상태

관리자 전용.

출력:

- 봇 버전
- 전체 활성/중지 상태
- 공급자 configured 여부만 표시
- 최근 공급자 상태의 성공/실패 범주

키 값, 토큰, 허용 방 목록, 내부 URL은 출력하지 않습니다.

## 3. 오류 문구

| 오류 코드 | 사용자 문구 |
|---|---|
| INVALID_USAGE | 사용법: ... |
| NOT_FOUND | 정보를 찾지 못했습니다. 입력을 확인해 주세요. |
| NOT_CONFIGURED | 아직 운영자가 설정하지 않은 기능입니다. |
| PROVIDER_TIMEOUT | 외부 조회가 지연되고 있습니다. 잠시 후 다시 시도해 주세요. |
| PROVIDER_UNAVAILABLE | 외부 서비스 오류로 지금은 조회할 수 없습니다. |
| RATE_LIMITED | 요청이 많습니다. 잠시 후 다시 시도해 주세요. |
| BOT_PAUSED | 봇 점검 중입니다. |
| INTERNAL | 처리 중 오류가 발생했습니다. 요청 ID: ... |

## 4. 버전 호환

명령어 이름과 기본 출력 필드는 공개 계약입니다. 호환을 깨는 변경은 문서 버전, CHANGELOG, ADR을 함께 수정합니다.
