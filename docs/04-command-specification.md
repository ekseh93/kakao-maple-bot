# 명령어 명세

문서 버전: 1.0  
기본 접두사: !

## 1. 공통 파싱 규칙

1. 메시지 앞뒤 공백을 제거합니다.
2. 첫 글자가 !가 아니면 아무 응답도 하지 않습니다.
3. 명령어는 한글·영문 별칭에서 대소문자를 구분하지 않습니다.
4. 명령과 첫 인수 사이는 하나 이상의 공백으로 구분합니다.
5. 전체 입력이 300자를 넘으면 외부 호출 없이 사용법 오류를 반환합니다.
6. 알 수 없는 명령은 짧은 도움말을 반환하되 방별 속도 제한을 적용합니다.

### !정보

별칭: !캐릭터, !메이플, !캐릭

형식:

    !정보 <캐릭터명>

처리:

1. 이름을 검증합니다.
2. Nexon Open API에서 OCID를 조회합니다.
3. 기본 정보와 종합 스탯을 조회합니다.
4. 가능한 필드만 짧게 포맷합니다.

정상 출력:

    [메이플 캐릭터]
    캐릭터명 @ 스카니아
    Lv. 280 / 비숍
    길드: 예시길드
    전투력: 12,345,678
    HEXA: 코어 2개 / 총 레벨 45
    HEXA 코어 목록:
    ▸ 마스터리: 테스트 코어 Lv.30
    ▸ 강화: 강화 코어 Lv.15
    기준: Nexon Open API 2026-08-26
    상세: https://maple.gg/u/...

필드가 없으면 해당 줄을 생략합니다. 0이나 빈 문자열을 “알 수 없음”과 혼동하지 않습니다.

오류:

- 인수 없음: 사용법 표시
- 캐릭터 없음: “캐릭터를 찾지 못했습니다.”
- API 제한/장애: “Nexon 조회가 잠시 지연되고 있습니다.”
- 키 미설정: 운영자용 구성 오류 코드와 사용자용 미설정 메시지

### !로얄

```text
/로얄 [개수] [결과확인옵션(true/false)]
```

Nexon 공식 확률형 아이템 페이지의 현재 로얄스타일 목록과 표기 확률을 읽어 확률 가중치로 추첨합니다. 개수는 1~25개이며 생략 시 10개입니다. `true`는 개별 결과를 표시하고 `false`는 상세 결과를 숨깁니다. 응답에는 추첨 결과만 표시하고 기준일·안내 문구는 표시하지 않습니다. 결과는 실제 캐시 아이템을 지급하거나 구매하지 않는 미니게임이며, 목록 조회 실패나 공식 표 형식 변경 시 임의의 목록으로 대체하지 않습니다. 공식 페이지 응답은 5분간 캐시합니다.

표시되는 로얄스타일 결과에는 `[라벨]` 접두사를 붙입니다.

### !원더베리

```text
/원더베리 [개수] [결과확인옵션(true/false)]
```

Nexon 공식 위습의 원더베리 확률 페이지에서 가장 최근 확률표를 읽어 확률 가중치로 추첨합니다. 희귀 아이템에는 `[블랙]` 접두사를 표시합니다. 개수는 1~25개이며 생략 시 10개입니다. `true`는 개별 결과를 표시하고 `false`는 상세 결과를 숨깁니다. 응답에는 추첨 결과만 표시하고 기준일·안내 문구는 표시하지 않습니다. 결과는 실제 캐시 아이템을 지급하거나 구매하지 않는 미니게임이며, 목록 조회 실패나 공식 표 형식 변경 시 임의의 목록으로 대체하지 않습니다. 공식 페이지 응답은 5분간 캐시합니다.

### !부티크

형식:

    !부티크

넥슨 공식 부티크 기프트 확률표를 기준으로 10개를 엽니다. 1~9번째는 일반 확률표, 10번째는 공식 설명에 따라 피버 타임 확률표를 사용합니다. 결과에는 10개 추첨 목록만 표시하며 기준일·안내 문구는 표시하지 않습니다. 결과는 실제 아이템을 지급하지 않는 미니게임이며, 확률표 조회 실패나 형식 변경 시 임의의 결과로 대체하지 않습니다. 확률표는 5분간 캐시합니다.

### !루나스윗

```text
!루나스윗
```

원더 블랙 + 원더 블랙 조합 1회의 결과를 [일반 루나 크리스탈 스윗 공식 확률표](https://maplestory.nexon.com/Guide/CashShop/Probability/LunaCrystalSweet)로 추첨합니다. 일반 루나 스윗 펫은 `[스윗]`, 루나 쁘띠 펫은 `[쁘띠]`를 이름 앞에 표시합니다. 명령어는 인자를 받지 않으며 실제 캐시 아이템을 지급하거나 구매하지 않는 미니게임입니다.

루나 스윗펫 결과에는 `[스윗]`, 원더 드림펫 결과에는 `[뒤진펫]`, 루나 쁘띠펫 결과에는 `[쁘띠]` 접두사를 붙입니다. 사용자 응답에는 기준일·공식 URL·확률 기반 안내 문구를 표시하지 않습니다.

### !루나드림

```text
!루나드림
```

원더 스윗 + 원더 블랙 조합 1회의 결과를 Nexon 공식 확률 페이지의 현재 확률표로 추첨합니다. 명령어는 인자를 받지 않으며 실제 캐시 아이템을 지급하거나 구매하지 않는 미니게임입니다.

루나 스윗펫 결과에는 `[스윗]`, 원더 드림펫 결과에는 `[뒤진펫]`, 루나 쁘띠펫 결과에는 `[쁘띠]` 접두사를 붙입니다. 사용자 응답에는 기준일·공식 URL·확률 기반 안내 문구를 표시하지 않습니다.

### !날씨

```text
!날씨 <지역명>
```

Open-Meteo Geocoding으로 전 세계 지역명을 좌표로 찾고, 결과가 없으면 OpenStreetMap Nominatim을 한글 검색 fallback으로 사용합니다. 좌표는 현재 날씨 API와 Air Quality API에서 현재 상태·기온·습도·PM10·PM2.5를 조회합니다. 응답에는 지역·상태·기온·습도·미세먼지 정보만 표시하고 조회 시각과 안내 문구는 표시하지 않습니다. 지역명은 공백을 포함할 수 있으며, 결과는 5분간 캐시합니다. 대기질 수치는 관측소 실측값이 아닌 Open-Meteo 모델 기반 참고값입니다.

### !무릉

형식:

    !무릉 <캐릭터명>

Nexon Open API의 `character/dojang`에서 무릉도장 역대 최고 층수, 기록 시간, 기록일을 조회합니다.

### !유니온

형식:

    !유니온 <캐릭터명>

캐릭터명을 OCID로 변환한 뒤 Nexon Open API의 `user/union`에서 유니온 레벨·등급과 제공되는 아티팩트 요약을 조회합니다.

### !유챔

형식:

    !유챔 <캐릭터명>

캐릭터명을 OCID로 변환한 뒤 Nexon Open API의 `user/union-champion`에서 해당 계정의 유니온 챔피언 이름·등급·직업·휘장 능력치를 조회합니다. 출력은 각 챔피언의 `닉네임 (랭크 직업)`만 표시하고, 휘장 효과는 다음 항목별로 전체 합산합니다: 올스탯, 최대 HP/MP, 공격력/마력, 보스 몬스터 공격 시 데미지, 크리티컬 데미지, 방어율 무시. API 응답 기준이며 챔피언 능력치를 직접 추정하지 않습니다.

### !장비

형식:

    !장비 <캐릭터명>

캐릭터명을 OCID로 변환한 뒤 Nexon Open API의 `character/item-equipment`에서 장착 장비의 부위·이름·스타포스·잠재능력 옵션을 조회합니다. 카카오톡에서 읽기 쉽도록 `부위 - 스타포스 장비명` 형식으로 표시하고, 같은 잠재·에디셔널 옵션명의 수치는 장비별로 합산해 표시합니다. 목록 마지막에는 모든 장비의 같은 옵션명을 다시 합산한 `잠재 총합`과 `에디 총합`을 표시합니다. 응답이 1,000자를 넘으면 일부 장비만 표시합니다.

### !경험치 또는 /경험치

형식:

    /경험치 <캐릭터명>

Nexon Open API의 `character/basic`을 당일과 이전 7일 날짜로 조회해 총 8개의 경험치 스냅샷을 표시합니다. 각 날짜의 레벨·경험치 비율·전날 대비 변화율과 같은 레벨을 유지한 경우의 7일 변화·일평균·현재 레벨의 100%까지 예상 일수를 제공합니다. 원시 보유 경험치 값은 카카오톡 출력에서 제외합니다. API의 날짜별 데이터 특성상 레벨업이 포함된 기간의 비율 변화와 예상 일수는 단순 계산하지 않습니다.

### !악몽 / !앵글 / !마운틴

형식:

    !악몽 <캐릭터명>
    !앵글 <캐릭터명>
    !마운틴 <캐릭터명>

Nexon Open API 경험치 이력의 최신 스냅샷에서 캐릭터의 현재 레벨과 경험치율을 가져옵니다. 각 명령어에 대응하는 경험치 표의 레벨별 기본 보상을 사용해 `ceil((100 - 현재 경험치율) / 레벨별 1판 경험치)`로 레벨업까지 필요한 예상 판수를 계산합니다. `!악몽`은 280~299레벨, `!앵글`은 270~299레벨, `!마운틴`은 260~299레벨을 지원합니다. 현재 경험치율은 100% 미만이어야 하며, 보너스 단계는 반영하지 않습니다. 경험치 이력과 결과는 기존 경험치 조회와 동일하게 5분간 캐시합니다.

### !썬데이 / !선데이

형식:

    !썬데이

Nexon 공식 진행 중 이벤트 목록에서 제목에 `썬데이` 또는 `선데이`가 포함된 항목을 찾아 제목·기간·공식 링크와 상세 페이지의 공식 이미지 링크를 표시합니다. 결과는 5분간 캐시합니다. 레거시 MessengerBot R 릴레이는 이미지 파일 자체를 전송하지 않으므로 이미지 링크를 제공합니다.

### !공지

형식:

    !공지

Nexon Open API의 `notice`에서 최신 공지 최대 3건의 제목·날짜·공식 링크만 조회합니다. 공지 본문은 가져오지 않으며, 목록은 5분간 캐시합니다.

### 공지 키워드 자동 알림

Nexon 공식 공지 목록을 공기계 릴레이가 약 60초마다 확인합니다. 제목에 `채널 점검`, `마이너버전`, `클라이언트` 중 하나가 포함된 새 게시글만 허용 방에 한 번 전달합니다. 기존 게시글은 릴레이 시작 시 기준 목록으로 등록하며, URL을 중복 키로 사용합니다. 이 기능은 `NOTICE_ALERT_ENABLED=true`일 때만 동작합니다.

### !인벤

형식:

    !인벤

메이플스토리 인벤 자유 게시판의 공개 10추 모음(`my=chu`)에서 최신 게시글 5개의 제목만 조회합니다. 게시글 본문·작성자·댓글·추천 수는 가져오지 않으며, 응답 마지막에 10추 게시판 링크를 표시합니다. 결과는 1분간 캐시하고 외부 페이지 구조 변경·접속 제한 시 표준 외부 조회 오류를 반환합니다.

### !마빡도로시

형식:

    !마빡도로시

기준 검색: <https://www.inven.co.kr/board/maple/2304?name=nicname&keyword=%EB%A7%88%EB%B9%A1%EB%8F%84%EB%A1%9C%EC%8B%9C&eq=1&iskin=>

### !웹툰

형식:

    !웹툰

네이버 웹툰 공식 요일별 목록에서 완결·휴재 작품을 제외한 정식 연재 작품을 모아 무작위로 1개를 추천합니다. 작품명·작가·연재 요일·네이버 작품 링크를 표시하며 목록은 10분간 캐시합니다.

### !웹소설

형식:

카카오페이지 웹소설 메뉴, 문피아, 노벨피아의 공개 HTML에서 작품 후보를 수집해 1개를 무작위로 추천합니다. 결과 제목 앞에 출처 표기(`[카페]`, `[문피아]`, `[노벨피아]`)와 작품 링크를 표시합니다. 각 사이트의 클라이언트 렌더링·접근 제한·응답 구조 변경으로 후보를 읽지 못할 수 있으며, 접근 제한을 우회하지 않습니다. 후보 목록은 10분간 캐시합니다.

참고 링크: <https://page.kakao.com/menu/10011/>, <https://www.munpia.com/>, <https://novelpia.com/>

### !금주의신상

- 항목당 최대 30자이며 빈 항목은 허용하지 않습니다.
- 두 항목 중 하나를 균등 확률로 선택합니다.

출력: “항목 승리!”

### !뭐먹지

별칭: !메뉴, !뭐먹을까

형식:

    !뭐먹지

입력은 명령어만 허용합니다. 카테고리 인자는 더 이상 사용하지 않습니다.

출력:

- 추천 결과 1개만 표시
- 요리·사이드메뉴·디저트·술안주 목록에서 추첨
- `재획`은 다른 항목의 기본 가중치 1보다 1000% 높은 11 가중치를 적용

데이터: 저장소의 검토된 정적 목록

알레르기, 종교, 건강 상태를 추론하지 않습니다. MVP는 식당 추천이나 위치 접근을 하지 않습니다.

### !주식

형식:

    !주식 <국내 종목명 또는 6자리 코드>
    !주식 <미국 종목명 또는 티커>

정상 출력:

    [주식 시세]
    삼성전자 (005930)
    현재가: 00,000원
    전일 대비: +000원 (+0.00%)
    거래량: 0,000,000
    조회: 2026-08-26 15:30 KST
    참고용 정보이며 투자 권유가 아닙니다.

규칙:

- 국내·일본 종목은 Yahoo Finance 공개 조회의 일별 데이터, 미국 종목은 Tiingo의 일별 데이터를 사용합니다.
- 주문·계좌·잔고 API는 호출하지 않습니다.
- 국내·일본 종목명은 Yahoo Finance 검색 결과에서, 미국 종목명은 Tiingo 검색 결과에서 확인합니다.
- 같은 이름으로 여러 시장 후보가 확인되면 한국시장(KRX)·일본시장·미국시장으로 구분해 표시합니다.
- 국내·일본 조회는 별도 API 키 없이 Yahoo Finance 공개 엔드포인트를 사용하므로 응답 형식 변경이나 일시적인 차단 가능성이 있습니다.
- 장외 시간에는 공급자가 제공한 마지막 값임을 표시합니다.
- 공급자 미설정 시 키 발급 안내 URL을 직접 노출하지 않고 “운영자가 설정하지 않은 기능”이라고 답합니다.

### !다이소

형식:

    !다이소 <상품>

`mcp.aka.page`의 공개 상품 검색 facade를 Lambda에서 직접 호출합니다. LLM 호출이나 MCP 프로세스 실행은 없습니다. 상품·가격·픽업 정보는 조회 시점 기준 참고용입니다.

### !기름 / !유가

형식:

    !기름
    !유가

한국석유공사 오피넷 전국 평균 유가를 조회합니다. 휘발유·고급휘발유·자동차용경유·실내등유·자동차용부탄을 표시하며, 10분간 캐시합니다.

### !주유소

형식:

    !주유소 <지역>

한국석유공사 오피넷의 휘발유(`B027`) 최저가 주유소를 낮은 가격 순서로 3곳 표시합니다. `서울`·`부산`·`대구`·`경기` 등 시·도명을 반드시 입력하면 해당 지역 결과를 표시합니다. 지역을 입력하지 않거나 지원하지 않는 지역이면 사용법을 표시합니다. 결과는 10분간 캐시하며, 가격과 주소는 조회 시점 기준 참고용입니다.

### !환율

형식:

    !환율

무료 공개 환율 조회에서 USD·JPY의 원화 환산값을 읽어 1달러와 100엔 기준으로 표시합니다. 1분간 캐시하며, 공급자 갱신 주기에 따라 실제 외환시장 실시간 체결가와 다를 수 있습니다.

### !통계

형식:

    !통계

허용된 명령 요청이 처리될 때마다 도쿄 리전 DynamoDB의 익명 `TOTAL` 카운터를 1 증가시키고, 현재 누적 호출 수를 표시합니다. 방·발신자·메시지 원문은 저장하지 않으며, 카운터는 해당 테이블을 배포한 시점부터 시작합니다.

### !상태

관리자 전용.

출력:

- 봇 버전
- 전체 활성/중지 상태
- 공급자 configured 여부만 표시
- 최근 공급자 상태의 성공/실패 범주

키 값, 토큰, 허용 방 목록, 내부 URL은 출력하지 않습니다.

## 3. 오류 문구

| 오류 코드               | 사용자 문구                                                |
| ----------------------- | ---------------------------------------------------------- |
| INVALID_USAGE           | 사용법: ...                                                |
| NOT_FOUND               | 정보를 찾지 못했습니다. 입력을 확인해 주세요.              |
| NOT_CONFIGURED          | 아직 운영자가 설정하지 않은 기능입니다.                    |
| PROVIDER_TIMEOUT        | 외부 조회가 지연되고 있습니다. 잠시 후 다시 시도해 주세요. |
| PROVIDER_UNAVAILABLE    | 외부 서비스 오류로 지금은 조회할 수 없습니다.              |
| RATE_LIMITED            | 요청이 많습니다. 잠시 후 다시 시도해 주세요.               |
| BOT_PAUSED              | 봇 점검 중입니다.                                          |
| USAGE_STATS_UNAVAILABLE | 사용 통계를 잠시 조회할 수 없습니다.                       |
| INTERNAL                | 처리 중 오류가 발생했습니다. 요청 ID: ...                  |

## 4. 버전 호환

명령어 이름과 기본 출력 필드는 공개 계약입니다. 호환을 깨는 변경은 문서 버전, CHANGELOG, ADR을 함께 수정합니다.
