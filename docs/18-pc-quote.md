# PC 견적 명령어 설계

## 사용자 계약

```text
!다나와견적 <예산> <용도> [모니터포함]
```

예산은 원·만원·억 단위를 지원합니다. 용도는 게이밍, 작업용/전문가용, 영상편집/3D, 사무용을 지원합니다. 결과는 최대 3개 후보와 총액, 부품별 가격, 호환성, 출처, 조회 시각을 표시합니다.

`!견적`도 기존 사용자를 위해 동작하지만, PC 관련 명령어를 구분하기 위해 새 안내에서는 `!다나와견적`을 사용합니다. `100만원`은 100~199만원대처럼 해당 만원대의 상한 직전까지를 의미합니다.

## 다나와 조회 명령어

```text
!다나와 도움말
!다나와부품 <검색어>
!다나와최저가 <검색어>
!다나와가격비교 <검색어>
!다나와가격이력 <제품코드> [1|3|6|12]
!다나와부품상세 <제품코드>
!다나와호환성
```

각 명령어는 `kr-pc-deals-mcp`의 조회 도구로 변환되어 별도 ECS Adapter의 인증된 `POST /v1/tool`에서 실행됩니다. 가격은 조회 시점의 참고값이며, 상품 상세·가격이력은 검색 결과의 제품 코드를 입력해야 합니다. 호환성 검사는 MCP의 상태형 빌드 흐름을 사용하므로 부품을 먼저 구성하지 않은 호출은 검사 불가 안내를 반환할 수 있습니다.

## 구현 경계

`packages/core/src/pc-quote.ts`가 입력 정규화와 카카오톡 출력 포맷을 담당하고, `PcQuoteClient`가 외부 가격 공급자 경계를 담당합니다. Lambda는 `PC_DEALS_API_URL`과 `PC_DEALS_SHARED_SECRET`이 설정된 경우에만 Adapter를 호출하며, 동일 조건은 10분 캐시합니다.

현재 Adapter 계약은 `POST /v1/quote`입니다. MCP 서버는 stdio 프로토콜이므로 Lambda에 직접 내장하지 않고, 별도 Node HTTP Adapter가 MCP 도구를 호출해 이 계약으로 변환해야 합니다.

## 안전·정책 기준

- 가격은 구매 확정가가 아닌 조회 시점의 참고값입니다.
- 다나와·컴퓨존의 이용약관과 요청 제한을 준수합니다.
- 원문 HTML이나 대량 가격 데이터를 저장·재배포하지 않습니다.
- Adapter 장애는 `!견적`에만 영향을 주고 기존 명령어에는 전파하지 않습니다.
- 공급자가 예산을 초과한 후보를 반환하더라도 Lambda와 Adapter가 모두 예산 상한을 재검증합니다. 예산 내 조합이 없으면 초과 견적 대신 조건 미충족 안내를 표시합니다.
- 실시간 연동 전에는 mock provider로 입력·출력·오류 테스트를 완료합니다.

## 예시

```text
!다나와견적 100만원 게이밍
!다나와견적 150만원 영상편집 모니터포함
!다나와최저가 RTX 4060
```
